--------------------------------------------------------
 ★ 最初に読んでください（大事なこと）
--------------------------------------------------------

GitHub Pages は「無料プランでは誰でも見られる」仕組みです。
パスワードをかけることはできません。

そこで、次の2つで「実質的に主催者だけが見る」状態にします。

 (1) URLを人に教えない（検索では出てきません）
 (2) 検索エンジンに載せない設定を入れてある
     ・各ページに noindex の指定
     ・robots.txt を同梱

この状態なら、URLを知っている人以外はたどり着けません。
参加チームへの公開は、大会が近づいてから改めて行います。


--------------------------------------------------------
 手順1　リポジトリを作る（初回だけ・約3分）
--------------------------------------------------------

1. https://github.com/new を開く

2. 下記のとおり入力する

     Repository name  … natsuyasumi-cup
     Description      … （空でよい）
     Public / Private … ★ Public を選ぶ
                        （Private だと無料プランでは公開できません）

     「Add a README file」のチェックは ★ 外す

3. 緑の「Create repository」を押す


--------------------------------------------------------
 手順2　ファイルをアップロードする（約3分）
--------------------------------------------------------

1. このフォルダ（_GitHubアップロード_2026-08-19）を開く

2. 作られたリポジトリのページで
   「uploading an existing file」（または Add file → Upload files）を押す

3. 下記を ★ フォルダごと まとめてドラッグ＆ドロップする

     index.html
     u8.html
     u9.html
     robots.txt
     assets      ← フォルダごと。中に画像3枚

   ※ assets フォルダは、開かずに フォルダのまま 放り込んでください。
     中身だけ入れると画像が表示されません。

4. 下の「Commit changes」を押す


--------------------------------------------------------
 手順3　公開の設定をする（初回だけ・約2分）
--------------------------------------------------------

1. リポジトリの上のほうにある「Settings」を押す

2. 左の列から「Pages」を押す

3. Branch のところで
     None → main を選び、フォルダは / (root) のまま
   「Save」を押す

4. 1〜2分待ってからページを再読み込みすると、
   上のほうに公開URLが表示されます。


--------------------------------------------------------
 手順4　スマホで確認する
--------------------------------------------------------

□ トップページ（ポスターとカップ）が画面いっぱいに出るか
□ U8 のカップを押すと U8 のページに移動するか
□ U9 のカップを押すと U9 のページに移動するか
□ 8つのボタンを押すと、それぞれの項目に移動するか
□ 右上のハンバーガーで INDEX が開くか
□ 左上の ← でトップに戻れるか
□ 赤い「仮の組み合わせ」の注意書きが出ているか

※ すぐに反映されないときは、
  スマホのブラウザで「更新」を長押し →「キャッシュを消去して再読み込み」


--------------------------------------------------------
 2回目以降の更新のしかた
--------------------------------------------------------

1. 変更したファイルだけをアップロードする
   （同じ名前で上げると上書きされます）

2. リポジトリのページ → Add file → Upload files
   → ファイルをドラッグ → Commit changes

3. 1〜2分で反映されます

★ 反映されないときは、ブラウザのキャッシュが原因のことがほとんどです。
  結婚式サイトのときと同じで、まずキャッシュを消して確認してください。
